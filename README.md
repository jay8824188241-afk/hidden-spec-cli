mend is one patch tool for every AI edit format: unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits. It matches lines at three tiers (exact, trailing whitespace, indentation), supports creates, deletes, renames and moves, and writes nothing unless every edit succeeds.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
